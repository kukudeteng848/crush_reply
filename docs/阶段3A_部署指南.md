# 阶段 3A 部署指南：登录 + crush 列表首页

> 跟 init 那次差不多的流程，多了一个云函数 + 改了首页。3 分钟搞定。

---

## ✅ 第 1 步：部署 login 云函数（~1 分钟）

1. 微信开发者工具左侧文件树展开 `cloudfunctions/`
2. **右键 `login` 文件夹** → 选 **"创建并部署：云端安装依赖 (不上传 node_modules)"**
3. 等"上传成功"提示

---

## ✅ 第 2 步：重新编译预览（~30 秒）

按 **`Cmd + B`** 重新编译，模拟器会重启小程序。

---

## ✅ 第 3 步：观察首页

应该看到**两种情况之一**：

### 情况 A（理想）：空状态
```
       💌
   还没有 crush
点右下角 + 添加你的第一个心动对象

                          [绿色 + 按钮]
```
- 灰色背景（仿微信对话列表风格）
- 右下角浮动绿色"+"按钮
- 点 + 会弹 toast「下一步迭代（3B）实现」

✅ 看到这个画面，3A 就通过了。告诉我"3A 通了"，进入 3B。

### 情况 B：报错
```
⚠️ [某段错误信息]
请检查 login 云函数是否已部署
```
把错误信息截图发我，我帮你排查。常见原因：
- login 云函数还没部署
- login 云函数部署后等待 30 秒再刷新（云端有缓存）

---

## 🔍 验证登录是否真的成功

打开 **云开发面板 → 数据库 → users 集合**，应该能看到一条记录：
```
_openid: "oTYxxx..."（你的微信测试 ID）
nickname: "我"
avatar: ""
createdAt: 2026-05-16T..
updatedAt: 2026-05-16T..
```

这就是你的用户档案。如果没看到这条记录，说明 login 云函数没跑成功。
