# 阶段 3D-1 部署指南：长按删除 + crush 编辑

> 3D-1 纯前端改动，不涉及云函数。点编译就能用。

---

## ✅ 第 1 步：重新编译

点工具栏的 **↻ 编译** 按钮（或 `Cmd + B`）。

---

## ✅ 第 2 步：测试 3 个新功能

### 测试 A：长按 crush 卡片 → 编辑

1. 首页**长按**任意 crush 卡片（手指按住 ~600ms 不松，电脑模拟器用鼠标长按）
2. 底部弹出操作菜单：「编辑资料 / 删除 / 取消」
3. 点 **编辑资料**
4. 跳转到编辑页（标题变成"编辑 Crush"）
5. **所有字段都应该预填上原有数据**（昵称、性别、MBTI、星座）
6. 改任意字段 → 点保存 → toast「已保存」→ 返回首页能看到改后的内容

### 测试 B：长按 crush 卡片 → 删除

1. 首页**长按** crush 卡片
2. 选 **删除**
3. 弹确认框「删除「xxx」？聊天记录将不再显示，且无法恢复」
4. 点 **删除**（红字）
5. toast「已删除」→ 卡片消失

### 测试 C：长按聊天消息 → 删除

1. 进入任意 crush 的聊天页（先随便聊几句让有消息）
2. **长按**任意一组对话（左边 crush 气泡或右边 AI 卡片）
3. 弹「删除这一轮对话」
4. 点击 → 确认 → 该轮对话消失

---

## ✅ 第 3 步：去云开发后台验证软删除

云开发后台 → 数据库 → conversations（或 messages）集合 → 找到刚才"删除"的那条记录：

- 记录**还在**（这就是"软删除"，没真删）
- 但多了一个 `deletedAt` 字段，值是删除时间
- 小程序里查询时会自动过滤掉 deletedAt 不为 null 的记录，所以你看不见

**为什么用软删除：**
- 如果以后想做"回收站"功能，数据还在
- 防止用户误删后后悔
- 数据完整性（聊天记录是隐私）

## ❓ 常见问题

**Q：长按没反应？**
A：在模拟器里要用鼠标长按 800ms 以上。手机真机长按只需 ~500ms。

**Q：编辑保存后首页没刷新？**
A：首页用 onShow 钩子，返回时会自动刷新。如果没刷新，重新进入首页。

**Q：误删了能恢复吗？**
A：当前版本没做回收站 UI。如果要恢复，去云开发后台手动找到那条记录，把 deletedAt 改回 null 就行。
