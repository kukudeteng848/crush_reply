# 阶段 2 部署指南：建表 + 灌入风格 + 设置权限

> 跟着下面 3 步走，10 分钟搞定。截图标记的地方记得拍照发我，方便我验证。

---

## ✅ 第 1 步：部署 init 云函数（~3 分钟）

我已经在 `cloudfunctions/init/` 写好了"一键初始化"代码。你只需要把它上传到云端。

1. 打开**微信开发者工具**
2. 左侧文件树展开 `cloudfunctions/`
3. **右键点击** `init` 文件夹 → 选 **"上传并部署：云端安装依赖（不上传 node_modules）"**
4. 等待提示"上传成功"（大约 30 秒，会自动安装依赖）

> ⚠️ 如果右键看不到这个菜单：先点工具栏的 **"云开发"** 按钮开一下面板，关闭后再右键

---

## ✅ 第 2 步：触发 init 一次（~2 分钟）

部署完代码不会自动跑，得手动触发一次。

1. 点工具栏的 **"云开发"** 按钮，进入云开发后台面板
2. 顶部 Tab 切到 **"云函数"**
3. 列表里找到 **`init`** → 右边 **三个点 …** → 选 **"云端测试"**
4. 弹出窗口里**不用填任何参数**，直接点底部 **"运行测试"**
5. 等 2-3 秒，看到返回结果应该是这样的：

```json
{
  "success": true,
  "report": {
    "collections": {
      "users": "created",
      "conversations": "created",
      "messages": "created",
      "styles": "created"
    },
    "styles": {
      "inserted": 5,
      "skipped": 0
    }
  },
  "message": "初始化完成..."
}
```

✅ 看到 `success: true` 就是建表成功了。

> 如果看到红字报错，截图发我，常见原因是"依赖没装完"——等 1 分钟重试一次就好。

---

## ✅ 第 3 步：设置 4 张表的权限（~5 分钟）

这是最关键的安全步骤。**没设权限的话，A 用户能看到 B 用户的聊天记录**。

1. 云开发面板顶部 Tab 切到 **"数据库"**
2. 左侧应该能看到 4 个新集合：`users`, `conversations`, `messages`, `styles`
3. **逐个点开**，设权限（每个集合点右上角 **"权限设置"** 按钮）

### 权限对照表（照着设）

| 集合名 | 该选哪个权限模式 |
|--------|----------------|
| `users` | **仅创建者可读写** |
| `conversations` | **仅创建者可读写** |
| `messages` | **仅创建者可读写** |
| `styles` | **所有用户可读，仅创建者可读写** |

> 三张用户数据表都是同一个选项（仅创建者可读写），只有 `styles` 是"所有用户可读，仅创建者可读写"。
>
> **注**：云开发权限只管小程序端，PM 在云开发后台直接编辑和云函数操作不受这些权限限制（自带管理员权限）。

4. 全部设完后，告诉我"4 张表权限都设好了"

## ❓ 常见问题

**Q：上传云函数时报错"npm install failed"怎么办？**
A：右键 init 文件夹 → "在终端中打开" → 运行 `npm install` → 再上传一次。

**Q：触发 init 后报错 "permission denied"？**
A：云开发面板顶部头像 → 确认是用你自己的微信登录的（不是其他账号）。

**Q：styles 集合里看到的中文字段都是乱码？**
A：不会的，云开发后台对中文字段值显示正常。如果真乱码，截图发我。
