## ✅ 第 2 步：测试 4 个场景

### 场景 A：进入"我的资料"页

1. 打开首页，**顶部多了一栏**：
   ```
   ┌─────────────────────────┐
   │ [我]  我        >       │  ← 灰色头像 + 昵称"我" + 右箭头
   │       点击设置我的资料   │
   └─────────────────────────┘
   ```
2. 点这一栏 → 进入"我的资料"页
3. 看到大头像（默认占位） + 一栏"昵称：我"

### 场景 B：上传我的头像

1. 在"我的资料"页点大头像
2. 弹出"选择图片来源"：拍照 / 相册
3. 选一张图片
4. 看到"上传中..." → toast「已更新」→ 头像立刻变成你选的图
5. 返回首页 → 顶部栏的头像也变了 ✅

### 场景 C：改昵称

1. 在"我的资料"页点"昵称：我"那一行
2. 弹出可编辑的输入框
3. 改成"小明"之类的 → 确定
4. toast「已更新」
5. 返回首页 → 顶部栏昵称变了
6. 进入任意 crush 聊天 → 右侧（我这边）的头像和昵称都更新了 ✅

### 场景 D：给 crush 上传头像

1. 首页**长按** crush 卡片 → "编辑资料"（或者点 + 新建一个）
2. 编辑页顶部多了一个**大圆角头像**（默认是 crush 首字母）
3. 点头像 → 选图 → 上传 → toast「已上传，点保存生效」
4. 点底部"保存"
5. 返回首页 → crush 卡片的小头像变了
6. 进入聊天 → 左侧 crush 头像也是新的 ✅

## ❓ 常见问题

**Q：点头像没反应？**
A：可能基础库版本太低不支持 wx.chooseMedia。模拟器顶部"详情 → 本地设置 → 基础库版本"调到 2.10.0 以上。

**Q：上传报错"permission denied"？**
A：云存储默认是登录用户可读写。如果改过权限，回到默认"所有用户可读，仅创建者可写"。

**Q：上传成功但头像不显示？**
A：可能是 `<image>` 加载 cloud:// 失败。检查 Console 有没有报错，或者图片太大。`sizeType: ['compressed']` 已经压缩过，正常 < 200KB。

**Q：头像换了，但聊天页右边还是旧的？**
A：重进聊天页一次。globalData 是页面加载时读一次，复用页面不会自动刷新。3E 收尾时可以加自动刷新。

**Q：上传的旧头像怎么删？**
A：当前版本不会自动删旧头像（会留在云存储里）。要清理可以去云开发后台 → 云存储手动删。3E 或后续可以加自动清理逻辑。
