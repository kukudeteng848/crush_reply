# 阶段 3C 部署指南：聊天界面 + DeepSeek 接入

> 这是整个项目的核心环节。包含 3 步：部署云函数 → 设置 API Key → 测试聊天。约 10 分钟。

---

## ✅ 第 1 步：部署 generateReply 云函数（~1 分钟）

1. 在微信开发者工具的文件树里
2. **右键 `cloudfunctions/generateReply` 文件夹** → 选 **"创建并部署：云端安装依赖 (不上传 node_modules)"**
3. 等待"上传成功"提示（这次多了一个 axios 依赖，可能多花 10-20 秒）

---

## ✅ 第 2 步：⭐设置 DeepSeek API Key（最关键的一步）

云函数代码本身不带 API Key（出于安全考虑），要在**云开发后台**手动配置。

1. 点工具栏 **"云开发"** 按钮 → 顶部 Tab 切到 **"云函数"**
2. 列表里找到 **`generateReply`** → 点函数名进入详情页
3. 顶部 Tab 切到 **"函数配置"**（或者叫"配置"）
4. 找到 **"环境变量"** 区域 → 点 **"+ 添加变量"**
5. 填两个值：
   - **变量名**：`DEEPSEEK_API_KEY`
   - **变量值**：`sk-e1fae712b68d4b76ba8706a6802f6f6b`（你之前给我的那个 Key）
6. 点 **"保存"**

> ⚠️ 变量名必须**一字不差**叫 `DEEPSEEK_API_KEY`，大小写敏感
>
> ⚠️ 保存后云函数会自动重启加载新环境变量，不用重新部署

---

## ✅ 第 3 步：测试聊天功能

1. 按 **`Cmd + B`** 重新编译
2. 首页点你之前创建的 crush 卡片（如果没有，先点 + 加一个）
3. 应该进入聊天页：
   - 顶部标题是 crush 的昵称
   - 中间灰色背景，有一个 💬 空状态提示
   - 底部输入框 + 5 个风格 pill（默认选中第一个"幽默"）
   - 右下角"发送"按钮（灰色，因为还没输入）
4. **试一下完整流程**：
   - 在输入框里粘一条假装是 crush 发的话，比如 `在干嘛？`
   - 发送按钮变绿
   - 点风格"幽默"
   - 点发送
   - 右上方出现 crush 头像 + 白色气泡「在干嘛？」
   - 下方出现绿色气泡，里面是「• • • 思考中」动画
   - 等 3-10 秒，AI 返回 1 条回复
   - 卡片底部有 **「再来 2 条」** 按钮
   - 点 **「再来 2 条」**，会追加生成 2 条
   - 每条回复右侧有 **「复制」** 按钮，点了能复制到剪贴板

✅ 看到 AI 真的给你出回复了，3C 就通了。**这是整个项目的核心功能跑通时刻**🎉

## ❓ 常见问题

### Q：点发送后弹窗"no_api_key"？
A：第 2 步没做对。回去检查环境变量名是不是 `DEEPSEEK_API_KEY`（不能有空格，不能小写）。

### Q：弹窗"deepseek_call_failed"？
A：可能是：
- API Key 写错了（去 DeepSeek 后台重新复制一次）
- 余额不够（去 DeepSeek 充值）
- 网络问题（重试一次）

把弹窗里的 `detail` 内容截图发我看具体报错。

### Q：弹窗"empty_reply"？
A：DeepSeek 返回了空回复（很少见）。换个 crush 消息试试。

### Q：AI 回复的内容太正式/不符合风格？
A：去云开发后台 → 数据库 → styles → 找到对应风格 → 编辑 `promptInstruction` 字段，加更具体的描述。比如把"幽默"的指令改成"用东北话风格的轻松幽默回复..."

### Q：聊天界面打开后白屏或转圈？
A：截图发我，附上 Console 日志。
