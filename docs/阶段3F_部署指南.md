## ✅ 第 3 步：体验主动模式

### 流程 A：典型"破冰"
1. 进入任意 crush 聊天页
2. 在输入框上方看到**黄色提示条**：「💡 想主动找 xxx 聊？」
3. 点它，从底部弹出半屏弹窗：
   ```
   ─── 主动找 小琳 ───
   选个场景
   [💬 破冰] [📅 邀约] [🤗 关心]
   [🙏 道歉] [🎉 节日] [💡 其他]

   具体想说什么？（"其他"必填，其他场景可空）
   [____________________]

   将用风格：humor
   [取消]   [生成开场白]
   ```
4. 默认选中"💬 破冰"
5. 意图框留空（让 AI 自由发挥）
6. 点 **生成开场白**
7. 弹窗关闭，聊天区右侧出现 **黄色 AI 卡片**（区别于普通的绿色卡片），标签是「💬 主动·破冰」
8. **没有左侧 crush 气泡**（因为是你主动发起，对方还没回话）
9. 卡片内是 AI 生成的开场白，可以复制 / 再来 2 条

### 流程 B：带意图的"邀约"
1. 点黄色入口 → 选 **📅 邀约**
2. 意图框填："周末想约去看《热辣滚烫》"
3. 生成 → AI 会基于这个具体意图给邀约话术
4. 卡片顶部会显示「意图：周末想约去看《热辣滚烫》」让你回顾

### 流程 C：节日（AI 自动判断日期）
1. 选 **🎉 节日**
2. 意图可填可不填
3. 生成 → AI 会自动根据**今天的日期**判断最近的节日（七夕/圣诞/生日等）

### 流程 D：风格切换的影响
1. 同样选"破冰"
2. 切到「😏 撩拨」风格 → 再次生成
3. 同样的场景，输出明显更撩
4. 切「😎 高冷」→ 输出克制
5. **场景决定话题方向，风格决定语气调性**——这是这一版的核心产品逻辑

## ❓ 常见问题

**Q：弹窗里的"将用风格"显示的是英文 id（如 "humor"）？**
A：是的，弹窗显示的是 styleId（数据 id）。要显示中文名要从 styles 列表取 displayName，3F 没做这个细节，3E 之前的列表 pill 显示中文。如果你想看中文名告诉我，5 分钟改。

**Q：旧的 message 没 type 字段会不会出问题？**
A：不会。前端用 `item.type !== 'initiate'` 判断，旧消息没有 type 字段就走默认 reply 渲染。

**Q：节日场景 AI 没认出今天的节日？**
A：DeepSeek 的训练数据可能没覆盖最新的节日。可以在 styles 里给一个"节日"专属风格，或者用户在意图框补一句"今天是七夕"。

**Q：主动消息也可以删除吗？**
A：可以，长按那条主动卡片即可。删除规则跟普通消息一致（软删除）。
