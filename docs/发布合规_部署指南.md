# 发布合规改造 · 部署指南

> 本轮加了 3 件审核必备：内容安全检测 + 隐私协议弹窗 + 协议页面。
> 提审前**必须**部署完。

## ✅ 第 1 步：重新部署 generateReply 云函数

云函数代码（index.js）和权限配置（config.json）都改了，必须重新部署。

1. 微信开发者工具 → 文件树展开 `cloudfunctions/`
2. **右键 `generateReply`** → 选 **"创建并部署：云端安装依赖 (不上传 node_modules)"**
3. 等"上传成功"提示

> ⚠️ 这次新增了 `security.msgSecCheck` openapi 权限。部署后云函数自动获得该权限，**无需手动到云开发后台开通**。

点 **↻ 编译**。

## ✅ 第 3 步：体验 4 个场景

### 场景 A：首次启动弹隐私协议
> 注意：你电脑上已经"同意过"的话，要先清除本地缓存才能复现。
> 开发者工具顶部 → **清缓存 → 清除全部缓存**，再编译。

1. 重新编译后小程序打开
2. **应该立刻弹「用户协议与隐私政策」对话框**
3. 内容里说明了收集啥信息、AI 是谁
4. 两个按钮：「不同意」「同意并继续」
5. 点「不同意」→ 退出小程序（或再次弹）
6. 点「同意并继续」→ 进入首页
7. 之后再打开不会再弹（已记本地）

### 场景 B：协议页面可读
1. 首页顶部点"我"→ 进入我的资料页
2. 多了一张卡片，有两行：
   - 用户协议 ›
   - 隐私政策 ›
3. 点开都能看到完整的协议内容（白色卡片排版，分节）

### 场景 C：敏感内容自动拦截
1. 进任意 crush 聊天页
2. 在输入框输入一段**确定会被微信安全审核拦的话**（试个最简单的：粘一段含明显敏感词的政治/色情/暴力内容）
3. 选风格 → 发送
4. **应该收到错误提示**：「输入内容包含敏感词，请修改后重试」
5. 没有调用 DeepSeek（省钱）

### 场景 D：正常对话不受影响
1. 输入正常的对话内容（如"在干嘛？"）
2. 应该和之前一样正常生成回复
3. 没有性能感知差异（msgSecCheck 一般 100-200ms）

## ✅ 第 4 步：去微信公众平台做"隐私接口配置"（提审必需）

从 2023 年起，使用某些"用户隐私"相关接口的小程序必须在公众平台配置《用户隐私保护指引》。

1. 浏览器开 https://mp.weixin.qq.com/ 登录
2. 左侧 **设置 → 服务内容声明 → 用户隐私保护指引**
3. 点 **更新**
4. 勾选你的小程序使用的接口（基于我们的代码，至少要勾这些）：
   - `wx.cloud.uploadFile` 或对应的"上传文件"
   - `wx.chooseMedia` 或"选择媒体"
   - `wx.getStorageSync` （本地存储，通常默认包含）
   - "微信用户 OpenID" / "登录"
5. 收集目的统一填："为用户提供 AI 对话灵感生成服务，存储用户设置和聊天记录"
6. 提交审核（这个比正式版本审核快，一般 1-2 天）

> 这一步**不做的话**正式版本审核会被直接拒。

## ❓ 常见问题

**Q：内容安全检测会不会误判正常对话？**
A：微信的 msgSecCheck 主要拦"色情/赌博/政治/违法"四大类，正常情侣聊天词不会被拦。如果你测试时发现误判，把内容截图发我看。

**Q：弹隐私协议总是反复弹？**
A：可能是 `wx.setStorageSync` 失败了。Console 会有报错，把截图发我。

**Q：协议内容能改吗？**
A：能。直接改 `pages/privacy/index.wxml` 和 `pages/terms/index.wxml`，是纯文本结构很好读。

**Q：体验版可以跳过这些合规吗？**
A：体验版不强制走完整审核，但内容安全检测**永远生效**（云函数代码层面）。建议正式版前先用体验版自测一遍。
