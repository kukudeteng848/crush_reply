## 一、产品是什么

**一句话**：当用户收到 crush（暗恋对象）的微信消息却不知道怎么回时，输入消息+对方资料+想要的语气，AI 立刻给出几条可以直接复制粘贴的回复。

**核心使用场景**：
1. 用户打开小程序 → 一键微信登录
2. 设置 crush 信息：性别（必填）、MBTI（选填）、星座（选填）、头像、昵称
3. 进入聊天界面（视觉和微信一模一样）
4. 把 crush 发来的消息复制进去 → 选择回复风格（幽默 / 暖心 / 高冷 / 撩拨…）
5. AI 在右边气泡生成多条回复建议，点一下复制
6. 历史对话保留，方便查看

## 二、技术方案（用产品语言解释）

| 组成部分 | 技术选型 | 用大白话说就是 |
|---------|---------|-------------|
| 前端（用户看到的界面） | 微信原生小程序 | 直接用微信官方的 UI 工具，做出来的界面和微信原生最像 |
| 后端（服务器） | 微信云开发 | **不需要买服务器、不需要域名备案**。腾讯把服务器、数据库、登录都打包成了"开箱即用"的服务 |
| AI 模型 | DeepSeek-V3 | 国产顶尖中文大模型，按字数计费，做 demo 一杯奶茶钱够你测一个月 |
| 用户登录 | 微信一键登录 | 用户点一下就能登，拿到的是微信给的"匿名 ID"，不需要手机号 |
| 数据库 | 云开发自带 | 存用户资料、聊天历史，免费额度够 demo 阶段用 |
| 头像存储 | 云开发存储 | 用户上传的头像图片放这里 |

**为什么不用自建服务器？** 因为微信小程序要求所有后端域名必须做 ICP 备案（个人备案 1-3 周，企业更久），而云开发**完全跳过这个流程**。这是 demo 阶段最快的路径。

## 五、风险和注意事项

| 风险 | 说明 | 应对 |
|------|------|------|
| 类目审核敏感 | "恋爱辅助/AI 回复"类目微信审核可能拒 | demo 阶段不提审；上线前换包装为"社交沟通辅助工具" |

| 用户隐私 | 聊天内容涉及个人 | 数据库做用户隔离；不存明文 API Key |
| **免费云环境到期** | 开发期 6 个月、上线后只 15 天免费 | 设好闹钟到期前 1 周做决定：升级付费 / 注销重建（重建会丢数据） |
