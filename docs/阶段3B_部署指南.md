## ✅ 第 2 步：体验完整流程

### 测试 1：点 + 按钮

1. 在首页点右下角绿色 **+**
2. 应该跳到「添加 Crush」页面
3. 表单包含 4 个字段：
   - 昵称（默认填了 "crush"）
   - 性别（必填 *，文本框，占位"男 / 女 / 其他"）
   - MBTI（点开是 16 种 + 不填的滚轮选择器）
   - 星座（点开是 12 个 + 不填的滚轮选择器）
4. 底部有绿色「保存」+ 白色「取消」按钮

### 测试 2：不填性别直接保存
- 点保存 → 应该弹 toast「请填写性别」

### 测试 3：完整填写并保存
- 昵称：随便填或保持 crush
- 性别：填"女"
- MBTI：选 INTJ
- 星座：选双子座
- 点保存 → 应该看到「已添加」绿色 toast → 自动返回首页

### 测试 4：首页能看到新 crush

回到首页后应该看到：
- 不再是 💌 空状态
- 而是一张白色卡片：
  - 左边：绿色方块，里面是大写首字母（如 "c"）
  - 中间：昵称 + "还没有聊天，快开始吧"
  - 右边：时间（"刚刚"）

### 测试 5：再加一个 crush，验证多条列表
- 再点 + 加第二个 crush（用不同昵称）
- 首页应该显示 2 张卡片
- 按添加顺序倒序排列（新加的在最上面）

## ❓ 常见问题

**Q：点 + 没反应？**
A：检查 app.json 里 pages 数组是否有 `"pages/crush-edit/index"`，没有的话 Cmd+B 重新编译。

**Q：保存时报"permission denied"？**
A：是 conversations 表的权限没设。回到 [阶段2_部署指南.md](阶段2_部署指南.md) 第 3 步，确认 conversations 选的是「仅创建者可读写」。

**Q：MBTI/星座的滚轮选择不像微信原生？**
A：是的，这是小程序内置的 picker，没法 100% 复刻微信对话页的样式。要更原生可以用 weui 组件库或自己造轮子，3E 收尾时可以考虑。
